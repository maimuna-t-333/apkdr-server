
# 🩺 Doctor Booking Backend

This is a simple backend for a doctor booking system using **Node.js**, **Express**, and a local JSON file (`doctors.json`) to store doctor data.

# 📁 Project Structure

doctor-booking-backend/
├── data/
│   └── doctors.json         # Stores all doctor info
├── index.js                 # Main server file
├── package.json
└── README.md                # This file

## 🧪 How to Test the API

You can test the backend using any of the following tools:

- ✅ **Postman**: Great for full control and sending body data.
- ✅ **Browser**: For simple GET requests like `/` or `/doctors`.
- ✅ **Frontend App**: Connect your frontend with this backend via `fetch` or `axios`.
